# whos.baby ✨

> The ultimate aesthetic biolink platform inspired by guns.lol and feds.lol.

## Features (In Development)
- 🔗 **Unique Vanity Slugs**: Claim your unique handle (`whos.baby/[username]`)
- 🎵 **Audio & Music Player**: Custom audio tracks with click-to-enter splash screen
- 🎨 **Deep Customization**: Glassmorphism cards, glowing borders, custom cursors, animations
- 👾 **Discord Presence**: Real-time rich presence & status integration
- ⚡ **Instant Live Preview**: Edit your bio, links, and themes with immediate preview
- 📱 **Mobile Optimized**: Fast, responsive, and lightweight

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
